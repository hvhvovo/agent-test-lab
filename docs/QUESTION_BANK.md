# 题库维护

在 `app/question_bank.py` 添加题目，字段包括 id、skills、category、level、question、follow_ups、checkpoints、pitfalls。ID保持唯一，技能必须来自 `app/skills.py`。

主问题写清场景、现象与约束；追问应改变一个条件，检查是否理解取舍；考察点写可检查的行为，避免只列技术名词。常见误区用于区分“知道名词”和“能解释方案”。题目为工程场景编写，不宣称出自某公司真实面试。

示例：

- 现象：第四次工具结果返回后程序退出。
- 主问题：怎样分别设置工具次数和模型轮次？
- 追问：一轮请求三个工具怎么算？预算用尽后再请求怎么办？
- 要点：执行前检查整批预算；保留收尾；断言实际工具执行次数。

修改后执行 `python -m pytest tests/test_question_bank.py -q`。报告保存题目快照，旧报告保留原题。选择算法不随机：优先覆盖未出现的技能和类别，适合回归比较。当前没有间隔复习或自动难度调整。
