# 接下来的学习顺序

按模块复现功能，再用失败用例检查理解。

1. 保留当前能运行版本，先逐行解释 app/skills.py 的 extract_skills。
2. 独立写正常匹配、无匹配、空名单、大小写四个 assert，再对照参数化测试。
3. 修改一个规则，故意让测试失败，读失败信息，再修复。
4. 解释请求模型为什么要拒绝空字符串，以及422和500区别。
5. 用 /docs 手动创建报告，再看测试如何自动发送同样请求。
6. 阅读SQLite读写，理解为什么使用临时数据库和参数化SQL。
7. 区分词项检索和embedding检索；设计反例而不是只测容易通过的例子。
8. 阅读Mock供应商响应，解释工具循环和引用检查。
9. 配置自己选择的模型，记录真实成功/失败/延迟，不直接把Mock结果用于简历。
10. 每次只修改一件事，自己写commit说明；维护已知问题。

简历只写自己能解释、复现和追问的部分。覆盖率高并不代表需求充分、语义正确或生产可靠。
