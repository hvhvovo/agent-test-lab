# 围绕项目准备技术面试

按下面五轮学习，每轮先运行一个例子，再解释代码，最后自己改一处并补测试。无需一次背下所有文件。

| 轮次 | 文件 | 学会后要能回答 |
|---|---|---|
| 1：从请求到报告 | main.py、core.py | 输入怎么校验、函数如何传参、为什么返回422 |
| 2：工具循环 | llm.py、test_agent_budget.py | 4次工具和5轮模型有什么区别、整批参数为什么先检查 |
| 3：经历依据 | grounding.py、test_grounding.py | 引用合法为何仍会胡编、降级为何会误拦 |
| 4：测试设计 | test_practice.py、test_llm.py | Mock替代了什么、真实模型还缺哪些验证、数据库如何隔离 |
| 5：评测 | evaluate.py、evaluate_llm.py | Recall与MRR怎么算、未评审和失败如何计入、为什么小样本不代表生产效果 |

第一步先运行 `python -m scripts.reproduce_grounding`，解释两段输出区别。再把资料改为明确已完成的经历，预测防线是否触发，验证你的判断。

面试描述按实际能复现和解释的范围说。测试数量、覆盖率和模型质量分别说明，不互相替代。
