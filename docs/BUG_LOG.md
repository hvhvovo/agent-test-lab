## Agent 工具调用达到上限后无法正常收尾

状态：已修复，已通过本地 Mock 测试及回归测试。

### 问题现象

模型连续四轮请求调用工具后，程序直接结束并报错，

没有机会根据最后一次工具返回的结果生成答案。

### 复现方式

使用 Mock 设置五次模型响应：

前四次请求调用 search_profile，第五次返回合法的最终答案。

修改前，程序在读取第五次响应之前报错。

### 原因

模型交互最多四轮，工具调用也最多四次，

没有为工具预算用完后的最终回答保留交互机会。

### 修改方案

工具调用上限保持四次，模型交互上限调整为五轮。

执行工具前检查累计调用次数，超过预算就拒绝执行。

### 验证结果

1. 四次工具调用后，第五轮返回答案：通过。

2. 第五轮继续请求工具：被拒绝，工具实际只执行四次。

3. 完整回归测试：57 passed，2 条依赖弃用警告。

### 验证范围

使用 Mock 验证控制逻辑，尚未验证真实模型的收尾表现。

## B013：引用ID校验无法阻止错误经历前提

在Mock重放中，资料“尚未做过 RAG”被问成“你在 RAG 项目中如何优化召回”，且引用ID合法。增加保守词法检查，整题替换为假设场景并记录原因；补齐否定、计划、归属、无证据和误拦边界。详细复现与残余限制见 [GROUNDING.md](GROUNDING.md)。这不是已观察到的线上事故。

## B014：降级后话题漂移

固定复现：原题“你在RAG项目中如何优化召回”，引用“尚未做过RAG”。旧版按JD轮换模板，可能选到提示词注入题。改为主问题主题路由，召回题使用召回质量假设模板；增加主题匹配、歧义、未知主题、去重与原始输入不变测试。主题规则仍可能误判，人工评测单独记录主题保留。

## B015：否定资料导致正常题误拦

来源：一条真实模型任务，2次检索，5道题。模型正确承认没有RAG经历，但v2仅看引用资料的否定词，替换了2道正常题。修复为题目经历前提与资料风险联合检查，覆盖主问题、追问和考察点。离线重放保留5道原题，12项新增回归测试通过；有限引语处理可能漏掉其他表述，不能声称消除语义误判。见GROUNDING.md的v3记录。

## B016：条件句与引语换词后再次误拦

6条真实任务中的negation与missing产生3次误拦，包括“不虚构经历”和“假设你负责”等表达。以句子范围处理条件语境，保留句外及追问中的显式经历检查；两份已保存报告离线回放均保留正常题。新样本效果仍待测试。
